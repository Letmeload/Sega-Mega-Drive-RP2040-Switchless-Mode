# Sega-Mega-Drive-RP2040-Switchless-Mode
This switchless mod is designed to use the LED on the RP2040 Tiny. It is therefore relatively simple and cheap to implement.

You should also install the two resistors—10k and 4.7k—to increase the chip’s lifespan. This ensures that only 3.3V reaches the chip, instead of the 5V from the reset button.


How to flash the RP2040 tiny:

Hold the Boot Button and connect it to the computer. A Datadrive appear, there you have to copy the .uf2 file. Thats ist.
